# TasksHub - Practical Tutorial 07

**TasksHub** is a mobile task management and student profile application built with React Native and Expo Router during Practical Tutorial 07. In this lab session, we implemented a hybrid navigation structure combining bottom tabs (Dashboad and Profile) with a modal stack screen (Add New Task). To ensure data persists even after the app is closed or restarted, we used @react-native-async-storage/async-storage with JSON.stringify() and JSON.parse() to locally save, retrieve, and clear task lists and student profile informatio. Additionally, we integrated expo-notifications to trigger immediate local device alerts whenever a new task is saved, and expo-image-picker with media library permissions to select, crop, and store a profile picture from the user's gallery.
